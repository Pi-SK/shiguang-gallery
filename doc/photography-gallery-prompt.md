## 摄影画廊网页 — 开发提示词

### 项目定位

为一名风光 / 人文 / 人像摄影师构建线上作品画廊。气质关键词：**克制、沉浸、现代与古典交织**。像走进一间灯光压暗的美术馆——墙面退隐，只有作品在发光。

### 核心体验

- **全屏逐张浏览（主模式）**：一次只呈现一张照片，占满视口，配作品标题 + 拍摄地点（左下角或底部居中，小字，不抢画面）。键盘 ← → / 滚轮 / 触屏滑动切换，切换动效仅为 600-800ms 的 opacity 渐变 + 极轻微 scale（1.00→1.02），无弹跳、无位移。
- **分类入口（辅助导航）**：顶部或侧边极简导航，分「山川」「市井」「面孔」三个系列（对应自然风光 / 人文纪实 / 人像），点击后进入该系列的全屏浏览流。导航本身在浏览时自动隐去，鼠标移至顶部时浮现。
- **首页/封面**：一张全幅代表作 + 摄影师名号（衬线体），向下滚动或点击后进入浏览。不设多余元素。

### 视觉规范

| 维度 | 规格 |
|------|------|
| 底色 | 近纯黑 `#0a0a0a` ~ `#111`，不用纯黑（避免 OLED 边缘过硬） |
| 文字色 | 主文字 `rgba(255,255,255,0.85)`，辅助信息 `rgba(255,255,255,0.5)` |
| 标题字体 | 衬线体：思源宋体 / Noto Serif SC（中文）+ Playfair Display 或 Cormorant（英文点缀） |
| 正文字体 | 无衬线体：思源黑体 / Noto Sans SC + Inter |
| 字号节奏 | 摄影师名号 ≥ 2rem；作品标题 1rem-1.1rem；地点/辅助 0.75rem-0.85rem，letter-spacing 微增 |
| 留白 | 文字与画面边缘保持 ≥ 2rem 呼吸距离 |
| 动效 | 仅 opacity + 极轻 scale；时长 600-800ms；easing: cubic-bezier(0.25, 0.1, 0.25, 1)；禁止弹跳、粒子、3D |

### 交互细节

- 图片加载：先显示低分辨率模糊占位（或纯黑），加载完成后 opacity 渐显，避免布局跳动。
- 光标：浏览区域默认隐藏光标（2s 无操作后），移动时恢复。
- 键盘：← → 切换，Esc 退出全屏浏览回到导航，数字键 1/2/3 快速跳转系列。
- 触屏：左右滑动切换，上滑显示/隐藏信息栏。
- 预加载：当前张显示时，静默预加载前后各 1 张。

### 内容结构（示例数据）

```
精选（首页全屏流）: 10-20 张，跨系列混编
系列-山川: 自然风光作品
系列-市井: 人文纪实作品
系列-面孔: 人像作品
```

每张照片数据结构：`{ src, title, location, series, aspect }`

### 技术约束

- **单文件 HTML**：CSS + JS 内联，零外部依赖（字体可用 Google Fonts CDN 或本地 fallback）。
- 响应式：桌面优先，移动端可用（竖屏照片自适应，文字不遮挡主体）。
- 图片使用占位符 URL（如 picsum.photos 或纯色块），方便后续替换为真实作品。
- 语义化 HTML + 基础无障碍（alt、aria-label、键盘可达）。
- 代码注释用中文，结构清晰分段。

### 美学参考方向（非照搬，取气质）

- 线上影展感：类似 Magnum Photos 摄影师个人页的沉浸度
- 排版克制：类似日本写真集的大量留白与文字极小
- 深色画廊：类似 Artsy 暗色模式的作品呈现方式
- 古典温度：衬线体标题 + 竖排可能性（如系列名可考虑竖排点缀）

### 验收标准

1. 打开即见全幅封面，3 秒内进入沉浸浏览状态
2. 切换照片时无任何布局跳动或闪烁
3. 文字信息可读但不争夺注意力
4. 导航在需要时能找到，不需要时完全消失
5. 移动端竖屏照片不被裁切，横屏照片不出现大面积黑边
6. 整体气质：安静、有呼吸感、像翻一本精装摄影画册
